The platform runtime uses Node.js built-ins. The development test suite uses ws under its upstream MIT license. Game engines, models, textures, audio and game-specific dependencies are no longer present in this platform source tree; their notices and licenses are maintained with each independent game repository and artifact.

Historical Git versions retain historical third-party notices. Do not infer that moving code or an asset into a deployment release changes its license or distribution rights.
